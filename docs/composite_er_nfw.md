# ER+NFW composite baseline (small appendix)

We test a composite model combining TFR (ER) with an added NFW halo to detect any residual halo need.

Scope
- Run on 3–5 representative galaxies from the ED-SPARC cohort with matched controls (σ_floor, D/i priors, masks, dynesty settings) across GR, NFW, TFR, and TFR+NFW.

Deliverables
- Evidence table (this file) with logZ and ΔlogZ vs NFW and vs TFR.
- Note whether the composite is favored (and by how much) or penalized (Occam), per galaxy.
