# Utils Module Documentation

This directory contains utility scripts and debugging tools.

## GPU Tools
- gpu_test.py: GPU testing and benchmarking
- debug_cupy_parallel.py: CuPy debugging

## Data Tools
- debug_npz.py: NPZ file inspection
- fix_gr_results.py: Result repair tool
- fix_json.py: JSON repair

## Utilities
- adjust.py: Parameter adjustments
- convert_checkpoint.py: Format conversion
- run_history.py: Run tracking
- scratch_pad.py: Development sandbox
