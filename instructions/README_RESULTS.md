# Results Module Documentation

This directory stores all output files from DDMM runs.

## Chain Directories
- chains_dynesty/: Standard Dynesty results
- chains_gr_*/: GR baseline runs
- Organized by run type and parameters

## Output Files
- .npz: NumPy archives with samples
- .json: Structured results and metadata
- .png: Plots and visualizations
- .log: Execution logs
