# DensityDependentMetricModel - Directory Structure Guide

This folder contains comprehensive documentation for each directory in the reorganized DDMM project.

## Documentation Files

1. **README_CORE.md** - Core physics modules and data infrastructure
2. **README_RUNNERS.md** - Execution scripts and Bayesian inference runners  
3. **README_DATA_LOADERS.md** - Survey-specific data loading modules
4. **README_TESTS.md** - Test suites and validation tests
5. **README_ANALYSIS.md** - Analysis and visualization scripts
6. **README_VALIDATION.md** - Model validation and verification tools
7. **README_RESULTS.md** - Output files and result directories
8. **README_EXTERNAL_DATA.md** - External datasets and references
9. **README_UTILS.md** - Utility scripts and debugging tools
10. **README_DOCS.md** - Documentation and figures
11. **README_LOGS.md** - Log files and run history

## Quick Navigation

### For New Users
Start with README_CORE.md to understand the fundamental physics modules.

### For Running Simulations  
See README_RUNNERS.md for execution scripts and parameter estimation.

### For Data Analysis
Check README_ANALYSIS.md for result processing and visualization.

### For Testing
Refer to README_TESTS.md for validation and testing procedures.
